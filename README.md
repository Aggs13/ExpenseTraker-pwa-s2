# ExpenseTracker PWA

Aplicación de control de gastos personales construida con React + Vite y empaquetada
como PWA instalable.

El proyecto y la documentación completa (incluido el Bonus 2 / User Story #9) están en
[`expense-tracker-pwa/README.md`](./expense-tracker-pwa/README.md).

```bash
cd expense-tracker-pwa
npm install
npm run dev
```
